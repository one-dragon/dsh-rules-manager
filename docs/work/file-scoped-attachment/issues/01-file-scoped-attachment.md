# 01 —— 文件级作用域规则的自动附着

- **Status:** ready-for-human
- **Type:** task
- **Spec:** `docs/work/file-scoped-attachment/spec.md`

## 要做的

`paths` / `globs` 从第一版起就被解析并挂在每条规则上，但没有任何东西去匹配它们：作用域写成 `src/**/*.ts` 的规则永远只是一行目录。让会话触碰（读 / 写 / 编辑）到匹配文件之后，这条按需规则在下一个请求里以正文常驻的形式出现，并且**不改写规则文件本身**。

## 验收

以 spec 的 User Stories 与 Testing Decisions 为准：附着判定纯模块穷举、视图层三处映射、端到端宿主接缝断言；只读承诺不破 —— 开关只写 `state.json`。
